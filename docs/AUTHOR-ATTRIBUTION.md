## Context

All commits made through the Claude Code CLI in this environment are attributed to the git user configured locally (`git config user.name` / `user.email`). No `Co-Authored-By` or AI attribution lines are added to commit messages, per project preference.

If commits appear under an unexpected author, update the local git config:

```bash
git config user.name "Your Name"
git config user.email "your@email.com"
```

This affects only new commits; rewriting the author of existing commits requires history rewriting (e.g. `git filter-branch` or `git filter-repo`) and a force push.
